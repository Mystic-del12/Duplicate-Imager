# Contributing Guidelines

Thanks for your interest in contributing to Duplicate-Imager.

## Before You Start

- Review the [Code of Conduct](./CODE_OF_CONDUCT.md).
- Check existing issues and pull requests to avoid duplicate work.
- For large changes, open an issue first to discuss scope and approach.

## Contribution Rules

1. Keep pull requests focused and small.
2. Describe **what** changed and **why** in your pull request.
3. Preserve existing behavior unless the change is intentional and explained.
4. Do not include unrelated refactors in feature/bug-fix pull requests.
5. Ensure code remains clear, readable, and consistent with current style.
6. Update documentation when behavior, usage, or flags change.

## Commit and Pull Request Expectations

- Use clear commit messages.
- Reference related issues when applicable.
- Include steps to reproduce bugs and verify fixes for bug-related PRs.
- Include screenshots or logs when they help reviewers understand the change.

## Reporting Bugs

When reporting a bug, please include:

- Operating system and Python version.
- Exact command used.
- Expected behavior vs actual behavior.
- Error logs or traceback (if available).
- Sample input details (without private data).

## Suggesting Features

For feature requests, include:

- Problem statement and use case.
- Proposed behavior.
- Any alternatives you considered.

## Questions

If you are unsure about a change, open an issue and ask before implementing.
